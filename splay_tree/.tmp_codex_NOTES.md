1. `beta_le_self_of_double_dec`: monotone `beta` + `DecreasesAbove threshold g`

   by monotonicity, contradicting the decrease).  Consequence: the double-step
   image is poly of exponent `d` (NOT `d^2`) in `a`:
   `g z ≤ c * (alpha (beta z + 1) + 1) ^ d ≤ c * (a + 1) ^ d` via `alpha_mono`.

   `F_two_eq : F 2 n = 2 ^ n`, `F_three_succ : F 3 (n+1) = 2 ^ F 3 n`,
   `two_pow_le_F_three` (via `F_mono_left`), `le_two_pow_self`,
   `sq_le_two_pow : 4 ≤ x → x * x ≤ 2 ^ x`.
3. `alpha_drop_step` (THE KERNEL): if `threshold < z` and `A0 ≤ a` then
   `alpha (g z + 1) + 1 ≤ a`.  Chain, with `x = a - 2 ≥ c + 4d + 5`:

   and `alpha_le_iff` collapses: `alpha (g z + 1) ≤ a - 1`.
   Only ONE exp-vs-poly comparison is needed, and only at exp-vs-LINEAR
   strength, because the tower recurrence `F 3 (x+1) = 2 ^ F 3 x` absorbs one
   exponential for free.
