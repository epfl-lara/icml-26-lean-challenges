\begin{definition}[X]
Proposition 8.19 states that if $F: M \to N$ is a diffeomorphism and $X$ is a smooth vector field on $M$, then there is a unique smooth vector field $Y$ on $N$ such that $dF_p (X_p) = Y_{F(p)}$ for every $p \in M$. Show that this can be false if $F$ is assumed only to be smooth and bijective: take $F: \mathbb{R} \to \mathbb{R}$ defined by $F(x) = x^3$ and $X = d/dx$ on $\mathbb{R}$.
\end{definition}
