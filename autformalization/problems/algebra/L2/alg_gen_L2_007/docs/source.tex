\begin{theorem}[ABM_algebra_L2_alg_gen_L2_007_item_1]
Prove the following ideal-theoretic characterization of $\gcd(f,g)$: given polynomials
$f,g,h$ in $k[x_1,\dots,x_n]$, then $h=\gcd(f,g)$ if and only if $h$ is a generator of the smallest
principal ideal containing $\langle f,g\rangle$ (i.e., if $\langle h\rangle \subseteq J$, whenever
$J$ is a principal ideal such that $J \supseteq \langle f,g\rangle$).
\end{theorem}
