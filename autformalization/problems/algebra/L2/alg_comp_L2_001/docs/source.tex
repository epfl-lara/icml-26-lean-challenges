\begin{definition}[expSet]
Suppose that $I = \langle x^\alpha \mid \alpha \in A \rangle$ is a monomial ideal, and let $S$ be the set of all exponents that occur as monomials of $I$. For any monomial order $>$, prove that the smallest element of $S$ with respect to $>$ must lie in $A$.
\end{definition}
